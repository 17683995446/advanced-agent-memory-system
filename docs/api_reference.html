Agent Memory System

高度模块化的 Agent 记忆管理框架，为 AI Agent 提供完整的短期记忆、长期记忆、知识图谱和结构化存储能力。支持语义检索、记忆衰减、版本控制、冲突检测等高级功能。

v11.0.0

系统概述

Agent Memory System 是一个面向 AI Agent 的记忆管理框架，模拟人类记忆机制，提供以下核心能力：

短期记忆（工作记忆） -- 临时上下文缓存，支持焦点管理和快速访问，容量有限但响应迅速。

长期记忆（向量存储） -- 基于语义相似度的持久化记忆，支持多种可插拔后端（ChromaDB / FAISS / 内存向量存储 / Redis）。

知识图谱 -- 基于 NetworkX 的实体关系图谱，支持实体搜索、路径查找和从文本自动构建。

结构化存储 -- 基于 SQLite 的偏好、事实和交互日志管理。

高级功能 -- 混合搜索引擎（RRF 融合）、记忆衰减、记忆压缩、冲突检测、版本控制、审计日志。

快速开始

安装

# 基础安装（零外部依赖，使用内置 FakeEmbedding）
pip install -e .

# 可选：安装真实嵌入模型支持
pip install sentence-transformers

# 可选：安装向量存储后端
pip install chromadb faiss-cpu

基本用法

from memory_system import AgentMemory, AgentMemoryConfig

# 1. 创建记忆系统实例
memory = AgentMemory()

# 2. 存储记忆
memory.remember(
    "Python 是一种广泛用于 AI 和数据科学的编程语言",
    memory_type="semantic",
    category="knowledge",
    importance=0.9,
    tags=["编程", "Python", "AI"],
)

# 3. 检索记忆
results = memory.recall("Python 编程语言", top_k=3)
for r in results:
    print(f"[{r['score']:.4f}] {r['content']}")

# 4. 获取上下文（用于 LLM 提示）
context = memory.get_relevant_context("Python 有什么用途？")
print(context)

# 5. 使用上下文管理器自动保存和释放
with AgentMemory() as mem:
    mem.remember("重要信息", importance=0.9)
    # 退出时自动调用 save() 和 close()

AgentMemoryConfig 配置

AgentMemoryConfig 是系统的主配置类，组合所有子模块配置。所有字段均有默认值，可直接使用 AgentMemory() 以默认配置初始化。

class AgentMemoryConfig
基于 Pydantic BaseModel 的配置类，支持类型校验和默认值。
short_term dict
短期记忆配置，传递给 ShortTermMemory 构造器。
默认值: {"working_memory_capacity": 7, "history_limit": 50}
long_term LongTermMemoryConfig
长期记忆配置，包含嵌入模型和向量存储设置。
默认值: LongTermMemoryConfig()
knowledge_graph dict
知识图谱配置。
默认值: {"enabled": True}
structured_store dict
结构化存储配置。
默认值: {"db_path": ":memory:", "enabled": True}
consolidation_threshold float
记忆巩固的重要性阈值，超过此阈值的工作记忆将被迁移到长期记忆。
默认值: 0.6
auto_consolidate bool
是否启用自动记忆巩固。
默认值: True
default_top_k int
默认检索返回数量。
默认值: 5

LongTermMemoryConfig 子配置

class LongTermMemoryConfig
长期记忆子配置，控制嵌入模型和向量存储后端。
embedding EmbeddingConfig
嵌入模型配置，支持 provider（auto/fake/sentence-transformer/openai）、model_name、device、dimension 等字段。
默认值: EmbeddingConfig()（provider="auto"）
vector_store dict
向量存储后端配置。支持 backend（memory/chroma/faiss）和 dimension 等参数。
默认值: {"backend": "memory"}
auto_consolidate bool
是否启用长期记忆层的自动巩固。
默认值: False

配置示例

配置示例
from memory_system import AgentMemory, AgentMemoryConfig, LongTermMemoryConfig

config = AgentMemoryConfig(
    short_term={"working_memory_capacity": 10, "history_limit": 100},
    long_term=LongTermMemoryConfig(
        embedding={"provider": "fake", "dimension": 64},
        vector_store={"backend": "memory"},
    ),
    knowledge_graph={"enabled": True},
    structured_store={"db_path": ":memory:", "enabled": True},
    consolidation_threshold=0.6,
    auto_consolidate=False,
    default_top_k=5,
)

memory = AgentMemory(config=config)

remember

categorystr 可选类别标签，用于过滤检索
importancefloat 可选重要性评分（0.0 ~ 1.0），影响记忆衰减和巩固
**kwargsAny额外参数：tags（标签列表）、source（来源）、metadata（元数据字典）等
返回值: str -- 记忆 ID
示例
memory_id = memory.remember(
    "Python 是一种解释型高级编程语言",
    memory_type="semantic",
    category="knowledge",
    importance=0.9,
    tags=["编程", "Python"],
)

def remember_fact( fact: str, category: str = "knowledge", source: str = "user", confidence: float = 1.0, **kwargs, ) -> str
参数类型说明
factstr 必填事实内容，不能为空
categorystr类别标签
sourcestr事实来源（如 "user"、"document"）
confidencefloat置信度（0.0 ~ 1.0）
返回值: str -- 记忆 ID

记忆检索

recall
回忆信息（核心检索方法，支持混合搜索引擎 RRF 融合）
def recall( query: str, top_k: int = None, from_short_term: bool = True, from_long_term: bool = True, exclude_sources: list = None, use_hybrid: bool = None, **filters, ) -> list
参数类型说明
querystr 必填查询内容
top_kint返回数量，默认使用配置中的 default_top_k
from_short_termbool是否检索短期记忆
from_long_termbool是否检索长期记忆
exclude_sourceslist排除的来源列表（如 ["structured"]）
use_hybridbool是否使用混合搜索引擎，None 表示自动判断
**filtersAny过滤条件：category、tags、memory_type、threshold、time_range、min_importance
返回值: list[dict] -- 检索结果列表，每项包含 content、score、source、memory_type、category、importance、timestamp、metadata、id
示例
# 基本语义搜索
results = memory.recall("Python编程语言", top_k=3)

# 按类别过滤
results = memory.recall("项目", top_k=3, category="work")

# 仅检索长期记忆，排除结构化数据
results = memory.recall("用户偏好", from_short_term=False, exclude_sources=["structured"])

# 使用时间范围和最低重要性过滤
results = memory.recall(
    "重要决策",
    time_range=(1700000000, 1735689600),
    min_importance=0.7,
)
recall_for_prompt
回忆信息并格式化为 LLM 提示文本
def recall_for_prompt( query: str, max_short_term: int = 3, max_long_term: int = 3, ) -> str
参数类型说明
querystr查询内容
max_short_termint短期记忆最大数量
max_long_termint长期记忆最大数量
返回值: str -- 格式化的记忆文本，包含【工作记忆】和【长期记忆】分区
示例
prompt_context = memory.recall_for_prompt("项目进度", max_short_term=2, max_long_term=5)
# 输出示例:
# 【工作记忆】
# - [工作记忆] 当前正在讨论项目进度 (相关度: 0.85)
#
# 【长期记忆】
# - [长期记忆] 项目Alpha的截止日期是2025年3月15日 (相关度: 0.72)
get_relevant_context
获取与查询相关的完整上下文（用于构建 LLM 提示）

返回值: str -- 格式化的上下文文本，包含【当前焦点】和检索到的相关记忆

snapshot = memory.get_working_memory_snapshot()
print(f"工作记忆项数: {len(snapshot.get('working_memory', {}))}")
